# MMCMate Management Site
A a simple web application for adding content in the MMCM Handbook.

## 🚀 Built With
- HTML, CSS, JavaScript
- Node.js (server folder)

## 🧩 Project Structure
```
/public     ← front-end files (UI, HTML/CSS/JS)
/server     ← back-end files (Node.js, APIs, etc)
.gitignore
package.json
package-lock.json
```

## 🔧 Getting Started

### 1. Clone the repo
```bash
git clone https://github.com/Joooban/MMCMate-Management-Site.git
cd MMCMate-Management-Site
```

### 2. Install dependencies
```bash
cd server
npm install
```

### 3. Setup / Configuration
(Explain any env variables, DB connections, etc)
- Create a `.env` file if needed (e.g., DB_URI, PORT)
- Adjust config in `server/config` (if applicable)

### 4. Run the app
```bash
# from /server
npm start
```
Then open `http://localhost:PORT` in your browser.

## 🎯 Features
- Add content to MMCM Handbook
- Responsive UI

## 🛠 Usage
1. Sign in
2. Navigate to the dashboard
3. Add information to the handbook
